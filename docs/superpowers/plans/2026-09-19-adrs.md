> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land ADR 1 under `docs/adr/`. Wire the ADR checks `SA-0110` built into the live records check. Teach the ontology, `DESIGN.md` and the citation test to read ADRs. Add the `adr-reviewer` agent, and rewrite the surfaces that still say Saffron keeps no ADRs.

**Architecture:** `SA-0110`, a cell, builds the `adr` kind in `records/`, its four checks and its CLI. It leaves the checks unwired, because `docs/adr/` does not exist yet. This plan is the rest, by hand, because `CONTEXT.md`, `DESIGN.md` and `.saffron/**` are `protected`:

- The live checks are wired next, then the readers and the index.
- The reviewer agent follows, then the surfaces.
- Last, the reviewer runs on this pull request.

**Tech Stack:** Python 3.12, pydantic 2, rdflib, pyshacl, pyoxigraph, pytest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-19-adrs-design.md`. The cell's half is `.saffron/specs/SA-0110-records-have-no-adr-kind.md`.

```python
def adrs(root: Path) -> list[Record]:
    return load(KINDS["adr"], root)


def _adr(record: Record) -> Adr:
    if not isinstance(record.model, Adr):
        raise TypeError(f"{record.path}: not an ADR record")
    return record.model


def add_adrs(graph: rdflib.Graph, records: list[Record]) -> rdflib.Graph:
    """Each ADR, what it supersedes, and the principles it rests on."""
    for record in records:
        m = _adr(record)
        node = FACTORY[f"adr-{m.id}"]
        graph.add((node, rdflib.RDF.type, FACTORY.ADR))
        graph.add((node, FACTORY.adrNumber, rdflib.Literal(m.id)))
        graph.add((node, FACTORY.adrStatus, rdflib.Literal(m.status)))
        for old in m.supersedes:
            graph.add((node, FACTORY.supersedes, FACTORY[f"adr-{old}"]))
        for n in m.principles:
            graph.add((node, FACTORY.restsOn, FACTORY[f"principle-{n}"]))
    return graph


def _status_cell(m: Adr) -> str:
    if m.status != "superseded":
        return m.status
    return "superseded by " + ", ".join(f"ADR {n}" for n in m.superseded_by)


def render_adr_index(text: str, records: list[Record]) -> str:
    """Rewrite the ADR index's table body from the ADR records."""
    body = ""
    for record in records:
        m = _adr(record)
        principles = ", ".join(str(n) for n in m.principles)
        body += f"| {m.id} | {_escaped(m.title)} | {_status_cell(m)} | {principles} |\n"
    start, end = adr_index(text)
    replaced = text[start + len(ADR_HEADER) : end]
    if replaced and not all(ln.startswith("| ") for ln in replaced.splitlines()):
        raise ValueError("the span after the ADR header is not a table body")
    return text[:start] + ADR_HEADER + body + text[end:]
```

### Task 5: The `adr-reviewer` agent

**Files:**
- Create: `.claude/agents/adr-reviewer.md`

`.claude/agents/` is in the `prose` gate's scope, so the new file is held to zero hits.

- [ ] **Step 1: Write the agent**

Model it on `.claude/agents/spec-reviewer.md`: the same frontmatter shape, read-only tools (`Read, Grep, Glob, Bash`), and "Bash for git reads only; write no file, run no test."

- **Inputs:** `adr:` a path under `docs/adr/`, and `base:` the commit to read at, defaulting to `origin/main`.
- **Read first:** the ADR, `CONTEXT.md` §11, the principle index in `DESIGN.md`, and every accepted ADR under `docs/adr/`.
  - For each principle the ADR lists, the reviewer reads the appendix that contributed it.
  - It also reads the appendices named in the ADR's `appendices`.
- **The four checks**, with severities (blocker, concern, note):
  1. **Principles missed.** For each principle in the index, whether the decision rests on it or departs from it and the ADR does not list it. It quotes the claim and the ADR sentence it bears on.
  2. **Verdict wrong.** An `upholds` that is a departure, or a `departs` whose reason does not answer the case the principle's appendix makes.
  3. **Conflict unrecorded.** An accepted ADR this one contradicts and does not list in `supersedes`.
  4. **Context unsupported.** A claim in `## Context` that the cited appendices do not support, quoted beside the appendix text.
- **Every finding** carries a file:line and the quoted text. A claim the reviewer could not check is marked **unverified**.
- **Output:** findings, then one line per check saying what was read, then "Mergeable after the listed fixes" or "Not mergeable". It is not a gate. Say why in one sentence: ADRs are `protected`, so no cell produces one.
