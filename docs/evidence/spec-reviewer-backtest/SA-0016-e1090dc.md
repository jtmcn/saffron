- **Blocker: criterion 1 (spec:43–47) doesn't require refusals to be keyed on the task.** DESIGN.md:347 says: "*Another* task, because a `CHANGES_REQUESTED` task re-queues (§3.3) while its own PR is still open … Refusal is keyed on `task_id`, not on the spec."
