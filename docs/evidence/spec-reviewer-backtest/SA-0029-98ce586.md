The fifth item on the spec's list, "the plan turn's own rejection" (`session.py:993`), is a plan-turn outcome. Its state is `PLAN_REJECTED`, not `NOT_IMPLEMENTED`.
  - **What the list leaves out:** `session.py:1009`, `watch(f"PLAN: the session failed, ${plan_cost:.2f} spent — {failed}")`. That ending is `NOT_IMPLEMENTED` with no commits, and nothing in the list can represent it.
  - **A false claim in Notes:** line 162 says "the code says so in as many words". The quoted comment (`session.py:1189-1191`) says "collapse a third fact into the two", which counts three, not five.
  - **Effect:** a cell built to the letter ships an enumeration that SA-0040's mapping table cannot complete. SA-0040 (`SA-0040-…md:119-122`) forbids a tenth kind and only allows a finding.
  - **Fix:** describe the enumeration as "the no-commit endings", and list the plan-session failure alongside the plan rejection.

- **Concern C2 (the name `GateResult` is already taken).** The criterion is at spec:72. `saffron/gates/contract.py:58` already defines `class GateResult(BaseModel)`, and its four statuses are `GateStatus = Literal["pass", "fail", "skip", "error"]` at `contract.py:15`.

- **Concern C3 (tight on turns and budget).** The frontmatter at spec:26-28 sets `max_turns: 110` and `budget_usd: 12`.

- **Concern C4 (the unwritable-path test proves nothing inside the cell).** The criterion is at spec:116-117 ("points it at an unwritable path and asserts the call returns").

  - **Fix:** require a path whose parent is a regular file (`NotADirectoryError`, which fails even for root). Also assert that nothing was written.
